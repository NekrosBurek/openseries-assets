# openseries-assets

Product images that [OpenSeries](https://github.com/NekrosBurek/OpenSeries) shows to identify connected devices. The app downloads only the images for devices you have plugged in, and caches them.

- `devices/`: 336×500 renders, named the way SteelSeries GG names them (`arctis_7.webp`).
- `hd/`: high-resolution transparent renders (about 1400 px), trimmed to the product (`arctis_7.png`).

Product images and the SteelSeries name and logo belong to SteelSeries ApS. They are used here only to show which device is connected. This repo is kept separate from the app's code, the same way OpenLogi mirrors Logitech's renders. If you are a rights holder and want something removed, open an issue and it will be taken down. The app falls back to generic artwork if an image is missing.
